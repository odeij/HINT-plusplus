# Eval Harness — R1 contracts

The harness is the ONLY way experiments run (no bespoke loops). It lives in `harness/` (planned —
scaffold here when Phase 7 work starts). Changes to contracts below are spec deviations → decision
record first.

## run_stream contract
```python
run_stream(method: MethodAdapter, stream: SceneStream, oracle: CorrectionOracle,
           budget: ClickBudget, seed: int) -> MetricsJSON
```
- Iterates scenes in fixed stream order; per scene: `method.predict` → oracle issues corrections
  under `budget` → `method.adapt_round` per correction round → final scene metrics.
- Deterministic given (stream, oracle config, seed): same inputs ⇒ byte-identical MetricsJSON
  (golden-output test enforces this).
- The runner computes ALL metrics from predictions + ground truth — methods never self-report
  metric values (F6: no self-scored metrics).

## MethodAdapter interface (adapter-or-nothing; see baseline-implement)
```python
class MethodAdapter:
    def reset(self, teacher_ckpt: Path, config: dict) -> None      # fresh state, per stream
    def predict(self, scene: Scene) -> Tensor                      # [N] class logits/labels
    def adapt_round(self, scene: Scene, corrections: list[Correction]) -> None
```
- `reset` must restore EXACT initial state (frozen-teacher identity for HINT++: Prop 1).
- Methods that don't adapt implement `adapt_round` as no-op (frozen teacher baseline).
- Clicks arrive only through `adapt_round`; an adapter has no other access to labels (leakage guard).

## Correction simulator (deterministic, AGILE3D protocol)
- Click placement follows the AGILE3D evaluation protocol (largest-error-region click), but regions
  are TRAINING-FREE: radius growing by default; geometric growing only via decision record (F8 —
  no learned maskers in evaluation).
- Seeded RNG per (stream, seed); identical click sequences across methods at the same budget —
  matched-budget comparisons are only valid because of this.
- **Noise mode:** corruption probability p ∈ {0, 10, 20, 30}% — corrupted click carries a wrong label
  (E2). **Burst mode:** adversarial sequence engineered to open-then-poison a class gate (E3).
- Golden-output tests: fixed synthetic scene + seed ⇒ exact expected click sequence committed in
  `tests/`; any simulator change that shifts goldens is a protocol change → decision record.

## MetricsJSON (versioned)
```json
{"schema_version": "1.x", "exp_id": "EXP-YYYYMMDD-NN", "git_sha": "...", "config_hash": "...",
 "method": "...", "stream": "...", "seed": 0, "budget": {...},
 "per_scene": [{"scene_id": "...", "miou_pre": 0.0, "miou_post": 0.0, "per_class_iou": {...},
                "clicks_used": 0, "events": [{"k": 0, "delta": 1, "h": 0, "gate": "OPEN"}]}],
 "aggregate": {"miou": 0.0, "rer": 0.0, "ccc": 0.0, "worst_stream_miou": 0.0,
               "harmful_rate": 0.0, "alpha_risk": 0.05, "s_per_round": 0.0, "pct_params": 0.0}}
```
- Bump `schema_version` on ANY field change; readers must check it. Event log is append-only and
  sufficient to recompute every aggregate offline (KL per round logged for Prop 2).

## Results storage
- Append-only under `experiments/results/{exp_id}/` — one MetricsJSON per (method, stream, seed),
  never overwritten; reruns get a new exp_id. Tables/figures are generated by scripts from these
  files only (no hand-edited numbers).
- Every file stamped with git SHA + config hash at write time; the registry row
  (`docs/experiments/registry.md`) links to the directory.

## Tests the harness must keep green
- Golden-output simulator tests (above); determinism test (two runs, same seed ⇒ identical JSON).
- Leakage guard: adapter API surface gives no path to target labels outside `adapt_round` corrections.
- Frozen-teacher round-trip: frozen adapter through the full runner reproduces teacher mIoU exactly.
- Schema validation on every emitted MetricsJSON.
