## Protocol (two tracks, zero target tuning)
- **Indoor (primary):** S3DIS→ScanNet, ScanNet→S3DIS, shared-class intersection (~8 classes; mapping
  table to be built and checked into `docs/`). **Outdoor (generality):** Synth4D→SemanticKITTI,
  Synth4D→nuScenes per GIPSO/HGL (source dataset pending DR-0002, due 2026-06-19).
- Targets are zero-shot: never train, tune, or compute feedback statistics on them.
- One global config across ALL streams; α_risk is the only deployment-semantic knob.

## Experiment sequence (order is mandatory)
1. **E1** Primary two-track table — all baseline families at matched budgets.
2. **E2** Noisy-oracle sweep, corruption p ∈ {0, 10, 20, 30}% — graceful-degradation curve.
3. **E3** Adversarial burst — the gate MUST close (BLOCKING; failure stops the experiment line).
4. **E4** Persistence vs episodic reset.
5. **E5** Ablations — only after E1 passes (gate-off = ungated-LoRA already doubles as a baseline).

## Metrics (model-agnostic — every method must be able to score them)
RER = % scenes with post-adapt mIoU < teacher − 1.0 pt · worst-stream mIoU · CCC = % streams with any
shared class >10 IoU below teacher · risk-budget adherence (empirical harmful rate vs declared α_risk)
· mIoU@k clicks · NoC@target · gain-per-click · s/round (~0.5 target), memory, % params updated.

## Baselines, grouped by what the human signal is used for
- **none:** frozen teacher, TENT, EATA/SAR, episodic reset, GIPSO+HGL (outdoor).
- **supervision:** HINT-3D source-thresholds, HINT-3D tuned, ungated-LoRA (gate-off ablation).
- **selection:** HILTTA-style online threshold selection (same clicks) — runs FIRST (most dangerous).
- **governance:** HINT++, oracle-tuned HINT++ (ceiling).
All behind `MethodAdapter` (see `baseline-implement`); each must reproduce one published number first.

## Reporting rules
- No hand-edited numbers anywhere: tables/figures are generated by scripts from `experiments/results/`.
- Every claim in the paper traces to a table, figure, or formal statement (Prop 1/2, Thm 1).
- Log to W&B; results append-only with git SHA + config hash (harness enforces this).
- A single-seed result is not a result; report mean ± std and the worst stream, not just the mean.
